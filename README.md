# SimsCraft : mises à jour

Ce dépôt sert uniquement à la mise à jour automatique du mod SimsCraft (Village Vivant) chez les joueurs du serveur.

- `version.txt` : le jar en service (nom, empreinte SHA-256, adresse de téléchargement).
- `maj_simscraft.ps1` et `script.txt` : le script lancé avant chaque partie, et son empreinte.

Les jars sont publiés dans les Releases. Aucun code source, aucun monde, aucun secret ici.
